# 물품 사진

`src/lib/goods-catalog.ts` 의 각 물품 `id` 와 파일명이 1:1로 맞는다
(`cap.png` ↔ `id: "cap"`). 파일을 바꾸면 화면도 바뀐다 — 코드는 안 건드려도 된다.

## 지금 들어있는 것

굿즈팀·의류팀 구글 시트의 `디자인 샘플` / `디자인 시안` 열에 얹힌 원본이다.
시트를 CSV로 받으면 이미지가 빠지므로 **xlsx로 받아** 압축을 풀면
`xl/media/` 에 원본이 그대로 들어 있다. 어느 이미지가 어느 행인지는
`xl/drawings/drawing1.xml` 의 앵커(행 번호)로만 알 수 있다.

원본은 500~2048px이고, 여기 있는 파일은 흰 바탕 256px 정사각형으로 맞춘 것이다
(카드가 64pt로 그리므로 3배율에 필요한 192px보다 한 뼘 여유).

노션 판매가 DB의 `사진` 열에도 사진이 있지만 전부 가로 95px이라 쓰지 않았다.

## 새 사진으로 바꿀 때

정사각형으로 자를 필요는 없다. 긴 변 600px 이상이면 충분하고, 흰 바탕이면
카드에 그대로 어울린다.
